## Linear workflow
- Linear is the task board. At the start of every session, use the Linear MCP to list open issues in the Samaktha project (team SRE) assigned to you or unassigned.
- Before starting an issue, move it to In Progress and comment that you're starting.
- Never invent tasks. Work only from Linear issues. If something new comes up mid-work, comment it on the issue instead of acting on it.
- When done, post a comment with: what changed, which files, and how to verify it. Then move the issue to In Review.
- If you're blocked or need a decision, post the question as a comment and move the issue to Blocked. Do not guess.
